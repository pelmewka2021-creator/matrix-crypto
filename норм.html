1. Введение в криптографию

1.1 Что такое криптография?

Криптография (от греч. kryptós — скрытый, gráphō — пишу) — наука о методах защиты информации путём её преобразования, исключающего чтение посторонними лицами[cite: 1].

Криптография решает три фундаментальные задачи[cite: 1]:

  • Конфиденциальность — информацию может прочитать только тот, кому она предназначена[cite: 1].
  • Целостность — информация не была изменена в процессе передачи[cite: 1].
  • Аутентификация — подтверждение личности отправителя[cite: 1].

2. Шифр Цезаря

2.1 История

Шифр Цезаря — один из древнейших известных шифров, названный в честь Гая Юлия Цезаря (100–44 до н. э.), который применял сдвиг на 3 позиции («А» → «Д», «Б» → «Е»)[cite: 1].

2.2 Принцип работы

Шифр Цезаря — это шифр замены со сдвигом[cite: 1]. Каждая буква алфавита заменяется буквой, стоящей на фиксированное число позиций вперёд[cite: 1].

Шифрование: E(x) = (x + k) mod n Дешифрование: D(x) = (x - k + n) mod n Где: x — порядковый номер буквы (А=0, Б=1, В=2 ...) k — ключ (величина сдвига) n — размер алфавита (для русского: 33, для английского: 26) mod — остаток от деления

2.4 Слабости шифра

  • Критически малое пространство ключей (всего 32 для русского языка)[cite: 1].
  • Уязвимость к частотному анализу[cite: 1].

3. Шифр Виженера

3.1 История

Описан Блезом де Виженером в 1586 году[cite: 1]. Три века считался неразгадываемым[cite: 1]. Взломан в 1863 году Фридрихом Касиски[cite: 1].

3.2 Принцип работы

Шифр Виженера — это полиалфавитный шифр замены с ключевым словом[cite: 1].

Шифрование: E(i) = (P(i) + K(i mod m)) mod n Дешифрование: D(i) = (C(i) - K(i mod m) + n) mod n

4. Машина Энигма

4.1 История и устройство

Электромеханическая шифровальная машина Артура Шербиуса (1918 г.)[cite: 1].

  • Клавиатура: 26 клавиш[cite: 1].
  • Роторы: непрерывно меняют схему замены[cite: 1].
  • Рефлектор: отправляет сигнал обратно[cite: 1].
  • Коммутационная панель: перестановка пар букв[cite: 1].

4.3 Взлом Энигмы

В 1940 году Алан Тьюринг создал устройство «Бомба» (Bombe) для автоматизированного взлома[cite: 1].

5. Современный стандарт AES

5.1 Предыстория: DES

Принятый в 1977 году DES (56 бит) к 1999 году взламывался за 22 часа[cite: 1].

5.2 Что такое AES?

AES (Advanced Encryption Standard) — симметричный блочный шифр (2001 год)[cite: 1].

ПараметрЗначение
Размер блока128 бит (16 байт)[cite: 1]
Длина ключа128, 192 или 256 бит[cite: 1]
Количество раундов10, 12 или 14[cite: 1]

5.3 Операции раунда AES

  1. SubBytes: Замена байтов по таблице S-box[cite: 1].
  2. ShiftRows: Циклический сдвиг строк матрицы State[cite: 1].
  3. MixColumns: Смешивание столбцов матрицы[cite: 1].
  4. AddRoundKey: XOR с раундовым ключом[cite: 1].
